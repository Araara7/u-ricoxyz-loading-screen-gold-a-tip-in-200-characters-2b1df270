## The tip

> Tip: your agent is pretending it understood the ticket on the first read. Give it a second — give yourself one too.

115 characters, one line.

## How it works

`main.py` writes the tip to `/output/entry.txt` (UTF-8, 1–200 chars, non-whitespace). No input, no network, no dependencies — Python 3 stdlib only.

```sh
python3 main.py
cat /output/entry.txt
```
